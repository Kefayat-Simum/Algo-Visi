# DSA Visualizer & Interactive Playground

An interactive web-based platform built with Vanilla JavaScript (ES6+), HTML5, and CSS3 to visualize Data Structures and Algorithms in real-time.

## 🚀 Live Demo
[View DSA Visualizer Live](https://your-username.github.io/dsa-visualizer/)

## ⚡ Features
- **Linear Structures:** Stack (LIFO) and Queue (FIFO) operations.
- **Sorting Algorithms:** Quick (Lomuto Partition), Bubble, Selection, Insertion, and Merge Sort with real-time robotic crane gantry animations, comparison/swap counters, and line-by-line code execution tracking.
- **Searching Algorithms:** Linear and Binary Search with range dimming and step execution.
- **Trees & Graphs:** Interactive Binary Search Tree (BST) rendering with animated in-order, pre-order and post-order traversals, and SVG-based BFS/DFS Graph traversals.
- **Shortest Path:** Dijkstra (priority queue) and Bellman-Ford (V−1 edge-relaxation passes) on weighted, directed graphs, with a live distance table and step forward & back. Includes sample graphs that show **Dijkstra failing on a negative edge** and **Bellman-Ford detecting a negative cycle**, plus a random graph generator.
- **Backtracking:** Step-by-step N-Queens recursion engine on an interactive chessboard.
- **Centralized Controls:** Play, pause, step-by-step navigation, and animation speed adjustments across all modules.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Custom properties, CSS Grid, Flexbox, Glassmorphism & Blueprint theme)
- **JavaScript ES6+** (Modular architecture, dynamic DOM & SVG rendering)
